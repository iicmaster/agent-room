## The five contract statements (ratified by the round-7 gate)

1. **v0.8.0 adds per-session identity provisioning, room discovery, and one-shot CLI
   send/read. Unbound sends use the authenticated key and server-selected durable
   attribution without claiming live occupancy.**
2. **accepted means durable commit, not wake or task completion. Retries preserve the
   idempotency key, payload and original name assertion; any post-attempt uncertainty is
   reported without claiming that no commit occurred.**
3. **The read cursor records fetched progress. Notification and hook delivery are
   best-effort with bounded queues and the documented loss accounting. Automatic wake is
   supported only for host integrations with matching native-session evidence; a stopped
   or unsupported host is not resumed by the transport itself.**
4. **session verify is a mutating, moment-in-time bind-and-release probe. Its receipt
   distinguishes confirmed release from failed or uncertain cleanup. It is neither a
   read-only query nor a reservation. The old-token fence does not revoke the private
   key: fresh same-key authentication may still send.**
5. **Normal wait fails closed on existing or stale locks. --reclaim is an operator force
   reset used only with all waiters and competing launches/reclaims quiesced; it does not
   provide concurrent takeover safety. Crash debris may remain beside the lock and is
   never re-imported.**
