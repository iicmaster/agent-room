## Findings

**F1 · The drill found and fixed a real production bug (again).**
Story 4.8's rehearsal exposed the multi-call recovery double-bind: concurrent recovering calls
reset the shared attach state and double-bound the Chat ID on the fresh server, wedging the client
~15 s per restart. Fixed via attach-epoch coalescing + single-flight `authenticateOnce()`. *Source:
`ffe5104`.* *Disposition: fixed; the gate design is validated — this is the second real bug a
blocking drill found (the first: 2.5's same-class discovery).*

**F2 · Two production bugs shipped inside a red fix-loop and were caught by hand.**
Story 4.7's implementation was interrupted mid-fix-loop; the hand completion found
`runtime.mjs`'s missing `STATE_FILE_MAX_BYTES` import (the TLS-material matrix passed vacuously —
refusal rows failed for the WRONG reason, which is a test-smell the review lenses now watch for)
and the CLI's non-awaited enroll dispatch (every coded refusal escaped as a raw error). *Source:
`562ea81`.* *Disposition: fixed; the vacuous-pass pattern added to the verification-gap lens's
watchlist.*

**F3 · The remote trust lane needed a production seam, delivered honestly.**
`AGENT_ROOM_CONNECTION_MODE=remote` (Story 3.5's seam) became 4.3's real transport policy path:
declared-remote clients skip ensureServer entirely, present no local token on any path (hardened
by 4.1's review), and speak the challenge lane. *Source: `5f7ce3f`.* *Disposition: accept — Epic
4's own stories are the seam's first production exercise.*

**F4 · The workflow's unattended proof advanced to phases 1–6.**
Story 4.1 ran plan → implement → suite gate → 4 reviews unattended (14 findings produced); the
provider failed at luna twice and the orchestrator's mid-run commits tripped the baseline guard —
both are process facts, and both guards now behave correctly (the guard caught REAL unscoped
product code in the diff; the escalation/race machinery had already been proven). *Source:
run records `dwfrun-{5c0422e6,8d47ae9b}*`, commits `59fc960`/`3b919e4` (advisory scope), `4ff0041`/
`5d7dea3` (guard semantics).* *Disposition: the unattended proof now covers phases 1–6; phases
8–10 (triage/patch/finalize) remain hand-backed pending provider stability.*

**F5 · Bookkeeping debt compounded.**
Story statuses in sprint-status lagged the work by up to five stories twice (Epic 1's retro and
this epic both had to correct them at retro time). The batch workflow now marks statuses in its
finalizer, and this retro corrects the remainder. *Source: the Epic 2 retro's F6 (same class).*
*Disposition: fixed going forward — per-story finalizers own their status flips.*
